# CS-370-Current-and-Emerging-Trends
CS 370 Current and Emerging Trends

This repository contains my Jupyter Notebook for the Pirate Intelligent Agent project. This project shows how I used reinforcement learning and neural networks to teach an agent how to navigate a maze and find treasure.

Briefly explain the work that you did on this project: What code were you given? What code did you create yourself?
I was given the foundational framework establishing the simulated game environment (including the maze structure via Python classes) and utility components like experience replay mechanisms. I developed the core deep Q-learning algorithm, defining the training loop, managing the state space, setting up reward strategies, and balancing exploration versus exploitation so the pirate agent could successfully learn the optimal path to the treasure.

What do computer scientists do and why does it matter?
Computer scientists figure out how to build and improve computer systems that handle everyday tasks, automate tricky processes, and solve real-world problems. This work matters because it makes technology actually useful for people, improves how things run, and helps solve everyday challenges—from finding the best routes and building smart tools to keeping data safe and making apps work smoothly.

How do I approach a problem as a computer scientist?
I approach problems step by step, breaking a big challenge into smaller, manageable pieces. Instead of trying to fix everything at once, I look at the rules and environment, test smaller fixes (like tweaking how a script behaves or adjusting its rewards), and continuously test, fix bugs, and refine my code until it works as intended.

What are my ethical responsibilities to the end user and the organization?
As a computer scientist, I am responsible for building software and AI models that are safe, fair, transparent, and reliable. This means ensuring that algorithms are free from unintended biases, respecting user privacy, protecting data integrity, and designing systems that maintain trust between the organization and the end user.
